A window with SDL3

An interactive window in safe Drachm over the SDL3 C library, with the unsafe part kept in one wrapper module.

examples/sdl3-window/ opens a window, draws into it, and takes keyboard and mouse input. It is the C imports guide as one program: the C library (SDL3) is called from one module, screen.drh, which gives the rest of the program a Window with safe methods and a Drachm enum of events. main.drh has no unsafe, no C type and no pointer in it.

It needs SDL3 installed (headers and library) and libclang, like any C import. Run it with:

InputEffect
WASD or the arrow keysmove the square
the mousea crosshair and a fading trail follow it
a clickpins a line from the square to the mouse
Spacecentres the square and removes the pin
Escape, or closing the windowquits

Without a display, SDL's dummy driver runs the same program for a number of frames: SDL_VIDEO_DRIVER=dummy WINDOW_FRAMES=120 drachm run examples/sdl3-window. cargo test does exactly that when SDL3 is installed.

The manifest

libraries links libSDL3, and unsafe = true lets the files of this project call C. The header, SDL3/SDL.h, is found on the system's include path.

The wrapper, screen.drh

Things worth noticing:

  • The union. SDL hands every event to SDL_PollEvent as an SDL_Event, a C union of about 50 structs. new sdl::SDL_Event of () makes it (zero bytes), (address of ev) as foreign *sdl::SDL_Event gives C its address, and ev.type says which member is valid. Reading ev.key.key or ev.motion.x is unsafe (E0336): the if on kind (the event type) above each read is what makes it sound.
  • SDL_FRect by pointer. SDL_RenderFillRect takes a pointer to a struct of four floats; fillRect builds the struct from plain numbers and hands over its address for that one call.
  • drop() releases the C handles. The renderer and the window are destroyed and SDL is shut down when the Window goes out of scope, including when main fails on the way out. No inference: the wrapper pairs the calls.
  • Errors become failures. C reports failure with a false result and a message from SDL_GetError(); openWindow turns that into a ScreenError that main passes up.
  • Events become an enum. Event is an ordinary Drachm enum, so main matches on it like any other.
