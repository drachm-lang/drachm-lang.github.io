Lesson 3: Decisions and loops

if and else, comparisons and bools, while, for, ranges, break and continue.

Goal: make a program choose between actions and repeat them.

Asking a question with if

A comparison such as hp < 10 produces a bool, which is true or false. if runs its block only when the condition is true, and else runs when it is not. The condition always sits in parentheses.

The block runs only when the condition is true.

Chain more questions with else if. The first condition that is true wins and the rest are skipped.

else catches everything that is left. Change hp and run the program again to see each branch.

The condition must be a bool

Drachm does not treat numbers as true or false. If you write if (n) with a number, the compiler stops and says so. Combine conditions with && (and), || (or) and ! (not); the right side runs only when it is needed.

Repeating with while and for

while repeats its block as long as the condition is true. The counter has to be mut, because the loop changes it.

The while loop tests n > 0 before every round, so the digits 3, 2 and 1 come out on one line.

A C-style for has three parts. The first runs once, the second is tested before each round, and the third runs after each round.

for (uint32 k of 5..8) is the short way to go over a range. The range includes both ends, so it counts 5, 6, 7, 8.

A range that starts above its end runs zero times. for (;;) has no condition, so it runs until a break leaves it.

Leaving a loop early

break leaves the innermost loop, and continue jumps to its next round. Put a number after either to count loops outward: break 2; leaves the loop and the one around it. Run this program and work out why each line prints what it does.
