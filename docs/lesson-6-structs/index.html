Lesson 6: Structs and methods

Grouping values in structs, building them, methods, static methods, mut fields, operators and public and private.

Goal: define your own types that group values and carry their own functions.

Grouping values in a struct

A struct is a type made of named fields. Everything declared under a public: label can be used by any code. A function written inside the struct is a method, and inside it self is the value the method was called on.

Point has two fields and one method. show reads the fields through self.

A field can itself be a struct, or a string. Named holds a name and a Point.

A value is built in a declaration by listing the fields in order. Point a = 1, 2; sets x to 1 and y to 2.

Or name them, in any order: y: 20, x: 10. Every field must be given exactly once, and mixing the two forms is an error.

Methods are called with ::, and fields are read with a dot.

Public and private

Fields and methods before any label are private fields and public methods. A public: or private: label changes the rule for everything after it. Private fields can be used only inside the struct's own methods. This is how a struct keeps its secrets: pin below can be checked with check but never read.

secret comes before any label, so it is private. owner and balance are public, and the private: label makes pin private again.

check is a method, so it may read pin.

Changing a field

A field cannot change unless something says it can. Either the binding that holds the struct is mut, or the field is declared mut. A mut field is for things that are meant to change, such as a balance. The compiler's message names both options.

Static methods

A static method has no self. It belongs to the struct itself and is called on the type, as in Temperature::boiling(). It is the natural way to build a value or to write a function that has nothing to do with one particular value. A method that never uses self should be static, and the compiler warns you if it is not.

Operators on your own types

An operator is a method named by the operator, and it takes the right-hand value. Money +(Money o) lets you write x + y, += uses it too, and a bool <(Money o) method gives you <. You can define + - * / % ** and the six comparisons. Without writing anything, == and != already compare two structs field by field.
