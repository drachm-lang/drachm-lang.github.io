Control flow

The rules for if, while, for, break, continue, skip and match.

The lessons cover decisions and loops and match and skip. This page gives the rules.

if, else if, else

The condition must be a bool, and it is always in parentheses. A number is not a condition (E0101). A function that returns a value must return on every path, or the compiler reports E0105. A loop with no break, such as for (;;), never falls out of its bottom, so no return is needed after it.

while and for

In a C-style for, the first part runs once, the condition is tested before each round, and the last part runs after each round. Each part may be left out, and the first part may declare a variable that exists only inside the loop. for (T x of a..b) goes over the inclusive range from a to b, and runs zero times if a is above b. The loop variable is not mut unless you say so, and changing it does not change the range. by n after the range sets the step: for (uint32 i of 0..10 by 3) runs for 0, 3, 6 and 9. The step is a value of the loop's type, and it stops at the last value not past the end.

A negative step counts down: for (sint32 i of 10..0 by -2) runs for 10, 8, 6, 4, 2 and 0. A step that points away from the end gives an empty loop, so 0..10 by -2 and 10..0 by 2 run zero times. A literal negative step also counts down over an unsigned loop variable and emits W0102. A step written as a literal zero is E0115. A step that is zero only when the program runs stops it at that point with the run-time error range step is zero (exit code 101).

A float range needs its by. Value k is start + k * step, computed from a whole-number counter, so the values do not drift. The loop stops at the last value not past the end: 0.0..1.0 by 0.25 runs for 0.0, 0.25, 0.5, 0.75 and 1.0, and 0.0..1.0 by 0.3 runs for 0.0, 0.3, 0.6 and then the third step, which is 0.9 up to float rounding. Without by a float range is E0101.

Looping over characters

for (string c of text) goes over the characters of a string, one at a time, in order. A character is a grapheme cluster, so an accent written as two code points, a \r\n pair and an emoji with joiners each count once; the number of rounds is the len() of the text, and an empty text runs zero times. Each c is a copy that can be kept or moved on. for (&string c of text) gives a borrowed view of each character instead, which cannot be kept: write copy c to keep one. The loop borrows the text, so the body cannot change it. break, continue and the rest work as in any loop.

Looping over a list

for (T x of xs) goes over the items of a list or array, first to last. T x gives a copy of each item (a plain read when the item is a number or another Copy type), &T x a view of it, and &mut T x a changeable view, which needs a list that allows changes. The variable's type must be the items' type: a uint32 list needs uint32 x, or E0630. The loop borrows the list for its whole length, so its body cannot push onto it (E0302). break, continue and skip work as in any loop. The list itself is in Arrays and lists.

break and continue

break; leaves the innermost loop and continue; starts its next round. A number counts loops outward, so break 2; leaves the innermost loop and the one around it, and continue 2; goes on with the outer loop. The number must be at least 1 and no bigger than the number of loops around the statement (E0011). continue in a C-style for still runs the step.

skip

skip leaves if blocks, as break leaves loops. skip; leaves the outermost if level that encloses it, up to the loop around it. skip N; leaves N levels, counting outward from the innermost, and skip to next; leaves the current branch and goes on to the next else if or else of the same chain.

A whole if / else if / else chain counts as one level, and each case of a match is also one level. Loops are walls, so a skip cannot leave the loop body it is in. A skip with no level to leave is error E0012.

match

match works on whole numbers, bool, floats, string and enums. Each case gives one value, a list separated by commas, or an inclusive range a..b, and case _ matches anything. The first case that matches runs and cases never fall through. A value may be a constant expression such as case 2 + 1, and the matched value is evaluated once.

A match must handle every value, or the compiler gives warning W0110; add case _ to catch the rest. On floats only case _ covers every value. A case after one that already matches every value it could match is warning W0111. break, continue and skip inside a case act on the enclosing loop or if, and a skip inside a match leaves the match, not a loop.

On an enum, a case names a variant and can bind, test and nest its values, and a missing variant is W0110 with the variants listed; see Enums.

A case on a number or text can have a guard, an if after the value: case 3 if x > 1 { }. The case runs only when the value is equal and the condition holds; otherwise the next case is tried. A guarded case does not count as covering its values, so a match whose only cases for a value are guarded still gets W0110, and needs a plain case or case _.

Matching text

On a string, each case gives plain strings, a list of them, or case _. A plain string matches the text exactly, * included: case "a*b" matches only a*b. To match a pattern, write globbed before the string: in case globbed "*.png", each * matches any run of characters, none included, and the whole text must match. globbed applies to the one string after it, so a list writes it on each: case globbed "*.png", globbed "*.jpg". Without a * a globbed string is an exact match too. The cases are tried in order, and the first one that matches runs.

The text is borrowed by the match, not moved, so a variable is still usable after it. string cases are checked the same way as the others: only case _ (or a case globbed "*") makes the match handle every text, so any other match on string gets W0110 with the note that text has too many values to list. A text case that can never run is W0111, but only when an earlier case clearly covers it: a repeated text, or a text that an earlier globbed case matches. Other overlaps are not reported.

Pausing a program

Import time to use time::sleep(duration). The call blocks the current thread. A bare number is in seconds. Import si to write a duration such as 20<ms>. Zero returns immediately. A negative, non-finite or unrepresentable duration stops the program with exit code 101.

Checking a condition: assert

assert(condition); is a statement that checks a bool. It works in any function, and it runs in every build, optimised -O builds included. A true condition does nothing. A false one stops the program at once with exit code 101, and prints the condition as you wrote it and the line it is on:
