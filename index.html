Drachm
  • Docs

A fast language that reads like English.

Statically typed and natively compiled. Cranelift for builds in milliseconds, C for -O speed.

Get startedGitHub
main.drh
none main() {
    uint32 hp = 100;
    hp = hp - 10;
}
$ drachm check main.drh
error[E0205]: cannot change `hp`: it is not `mut`
  --> main.drh:3:5
   |
 2 |     uint32 hp = 100;
   |            -- declared here without `mut`
 3 |     hp = hp - 10;
   |     ^^ assigned a second time here
   |
 help: declare it as `mut uint32 hp` to allow changes

main.drh: 1 error

Reads like English

Functions start with their return type, and keywords are plain words: with, of, lives, maybe, fails with, skip.

Two backends, one behaviour

Plain builds go through Cranelift and compile in milliseconds. -O builds generate C and run at C speed. The test suite checks they agree.

Ownership, no garbage collector

Moves and borrows are checked at compile time, so there is nothing to pause and nothing to leak.

Diagnostics that show their work

Every error has a code, the lines involved and a suggested fix. drachm explain describes any code.
